# AI Health & Nutrition Platform – Complete Antigravity Prompt Pack

## Project Overview
Build a web-based AI platform that can:
1. Calculate calories for any food  
2. Automatically calculate daily calorie needs  
3. Analyze clinical symptoms and suggest possible deficiencies/problems  
4. Estimate calories from food photos  

This document contains **full Antigravity prompts** for product design, system architecture, AI/ML pipeline, UI/UX, security, and roadmap.

---

## Antigravity Prompt 1: Master Product Spec
**Antigravity:**  
Act as a senior product architect and AI engineer.

Design a full product specification for a web platform that:
- Accepts food images and estimates calories & macros  
- Calculates daily calorie needs using BMR formulas  
- Analyzes user-reported symptoms and suggests possible deficiencies  
- Allows manual correction of detected foods  
- Uses trusted nutrition databases  
- Includes medical disclaimers and privacy compliance  

**Deliverables:**
- Feature list (MVP vs Phase-2)  
- User journeys  
- API contracts  
- Error handling strategy  
- Accuracy disclaimers  
- Regulatory considerations
